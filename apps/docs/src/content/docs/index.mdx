## Run your whole website in your own Cloudflare account

The website, contact form, admin panel, and database all run in your own Cloudflare account.

<LandingArchitecture />

Inquiry content stays inside Cloudflare, and even with Slack notifications, only a new-inquiry notice and a link to the admin panel are sent. Admin sign-in is passkey only, and you can add Cloudflare Access.

<FeatureNote>
  \* goodnight-web is not a SaaS for running websites. It is a starter kit for
  self-hosting, plus documentation for setting it up.
</FeatureNote>

</LandingSection>
