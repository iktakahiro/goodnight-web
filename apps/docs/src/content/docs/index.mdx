## Run your whole website in your own Cloudflare account

The website, contact form, admin panel, and database all run in your own Cloudflare account. The only services you need are Cloudflare and GitHub.

Inquiry data is neither stored nor sent anywhere outside Cloudflare. If you set a Slack webhook, Slack receives only a new-inquiry notice and a link to the admin panel, never what the visitor typed. Admin sign-in uses a passkey only, with no password, and you can add Cloudflare Access for another layer of protection.
