## No CMS, no third-party form service

Pages are static files, and inquiries live in your own database. The only services you need are Cloudflare and GitHub.

<FeatureGrid>
  <Feature visual='files' wide title='Content is managed as static files'>
    Pages, news, and the blog are static files such as Markdown. They are managed on GitHub and built with Astro.

    <FeatureNote>
      \* Includes `AGENTS.md`, a guide for AI tools.
    </FeatureNote>

  </Feature>
  <Feature visual='data' title='Keep personal data out of third-party form services'
  >
    The contact form is already built. Inquiries are saved to your own database, and you read them in the admin panel. Sign-in uses a passkey only, with no password.

    <FeatureNote>\* Inquiries are stored in a D1 database inside your own Cloudflare account.</FeatureNote>

  </Feature>
  <Feature visual='build' title='Serve the built files as they are'>
    The website is built with SSG, and the finished files are served directly from Cloudflare. Pages are not assembled on a server for each visit, so they load quickly.

    <FeatureNote>
      \* Served with Static Assets on Cloudflare Workers.
    </FeatureNote>

  </Feature>
  <Feature visual='starter' wide title='Start without building from scratch'>
    A starter kit with pages, a contact form, an admin panel, and a database in place from day one.

    <DeployButton variant="secondary" />

  </Feature>
</FeatureGrid>
