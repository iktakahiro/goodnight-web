## Just what you need, in your own account

No CMS (content management system) and no outside form service, so it is clear which services you use and what needs maintaining.

<FeatureGrid>
  <Feature icon='file-pen' title='Update pages by editing files'>
    Do it by hand, or ask an AI tool to do it.

    <FeatureNote>
      \* Built with Astro (a tool that builds websites from files). Includes a
      guide for AI tools (`AGENTS.md`).
    </FeatureNote>

  </Feature>
  <Feature
    icon='database'
    title='Keep personal data out of third-party form services'
  >
    Inquiries are saved to your own database. You read them in an admin panel you sign in to with a passkey (your face or fingerprint).

    <FeatureNote>\* Stored in a D1 database in your own Cloudflare account.</FeatureNote>

  </Feature>
  <Feature icon='git-pull-request' title='Maintenance is mostly reviewing updates'>
    Updates arrive as proposed changes (PRs). You review and apply (merge) them.

    <FeatureNote>
      \* Uses Cloudflare Workers, D1, and a GitHub repository (where your code
      lives). [See the full maintenance list →](/docs/maintenance/)
    </FeatureNote>

  </Feature>
  <Feature icon='layout-template' title='Start without building from scratch'>
    A starter kit with pages, a contact form, an admin panel, a database, and an update flow in place from day one.

    <FeatureNote>
      \* Set it up in your own account with the Deploy to Cloudflare button.
    </FeatureNote>

    <DeployButton />

  </Feature>
</FeatureGrid>

<CloudflareNote>

### What is Cloudflare?

Cloudflare is a company whose services deliver websites quickly around the world and protect them from attacks. Beyond delivering websites, it also offers ways to run programs and store data in databases.

This starter kit runs your website, contact form, database, and admin panel all inside your own Cloudflare account. With few services involved, it is clear what you are in charge of.

</CloudflareNote>
