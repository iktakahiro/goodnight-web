## Start here

- [Getting started](/docs/getting-started/): create a copy of the website with the Deploy to Cloudflare button, enter the secrets (private values stored with the Worker), and create the first admin.
- [Set up Turnstile](/docs/setup/turnstile/): create the widget for Turnstile, Cloudflare's bot check. The contact form does not accept submissions until you do.
- [Customizing the contact form](/docs/contact-form/): edit the fields in the admin screen. Also covers versions and history, the inquiry list, and the CSV export.

## Concepts

- [Architecture](/docs/architecture/): the parts of one website and what happens to a contact submission.
- [Database](/docs/database/): the D1 tables, how queries are written, and how migrations reach your website and are applied.
- [Distribution and updates](/docs/distribution/): what comes from the npm package and what you own in the starter, Dependabot updates, and why your repository must be private.
- [How it works](/docs/how-it-works/): how each part works and why it is built that way, such as passkey sign-in and deleting old data without Cron.

## Reference

- [Security model](/docs/security/): what protects the admin screen and the contact form, and what goodnight-web does not protect against.
- [Privacy notes](/docs/privacy/): where data is stored, how long deleted data can be restored, and what the privacy policy template says.
