goodnight-web is a starter kit for company and shop websites. It runs on Cloudflare: one Worker with Static Assets serves the pages and runs the API, and one D1 database stores the inquiries. The only other service is GitHub, where your website's repository lives. Slack notifications are optional.

## What you get

- **Pages and a blog.** A website built with Astro, with a home page, company profile, services, news, blog, contact page, and privacy policy, in Japanese and English. Blog posts are Markdown files in the repository.
- **A contact form.** You add, remove, and reorder its fields in the admin screen, with no code changes and no deploy. Submissions are checked with [Turnstile](/docs/glossary/#turnstile) and rate limited. Each one is saved to [D1](/docs/glossary/#d1) before the visitor gets a response.
- **An admin screen for inquiries.** You sign in with a [passkey](/docs/glossary/#passkey) instead of a password. You can read inquiries, mark them unread or read, search by email address, review suspected spam separately, delete inquiries, export them as CSV, and edit the form fields.

## Who it is for

- A developer or a small web agency that builds websites for clients and hands them over.
- Someone at a small company or startup who looks after the website. It also fits people without an engineering background who edit the site with AI tools.

You do not need to write server code. The contact API and the admin screen come from an npm package that you do not edit. Some maintenance remains; [Maintenance](/docs/maintenance/) lists it.
