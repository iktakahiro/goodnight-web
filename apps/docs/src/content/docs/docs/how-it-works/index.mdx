Each page covers one part of goodnight-web: what it does, the code that does it, and why it is built that way.

The code excerpts are short and copied from the repository. The file path is shown above each one, so you can read the whole file there.

- [Contact form protection](/docs/how-it-works/contact-protection/): Turnstile verified on the server, a honeypot field, a rule-based spam score, and the Rate Limiting binding.
- [Passkey sign-in](/docs/how-it-works/passkeys/): why admins use passkeys and not passwords.
- [First admin setup](/docs/how-it-works/first-admin/): how `SETUP_TOKEN` and `ADMIN_EMAILS` stop a stranger from becoming the first admin.
- [Deleting old inquiries without Cron](/docs/how-it-works/data-pruning/): how the retention period works with no scheduled job.
- [Slack notifications](/docs/how-it-works/notifications/): a short message after the reply, with no personal data.
- [No raw IP addresses](/docs/how-it-works/ip-hashing/): why only an HMAC of the IP address is stored.
