## CMSも外部のフォームサービスも使わない

ページは静的なファイルで管理し、問い合わせは自分のデータベースに保存します。必要なサービスは、Cloudflare と GitHub だけです。

<FeatureGrid>
  <Feature visual='files' wide title='コンテンツは、静的なファイルで管理する'>
    ページ、お知らせ、ブログは、Markdown などの静的なファイルです。GitHub で管理し、Astro を使ってビルドします。

    <FeatureNote>
      ※ AI ツール向けのガイドとして、`AGENTS.md` も入っています。
    </FeatureNote>

  </Feature>
  <Feature visual='data' title='個人情報を、外部のフォームサービスに預けない'>
    問い合わせフォームは実装済みです。届いた内容は自分のデータベースに保存され、管理画面で確認できます。ログインは Passkey だけで、パスワードは使いません。

    <FeatureNote>※ 問い合わせは、自分の Cloudflare アカウント内の D1 データベースに保存します。</FeatureNote>

  </Feature>
  <Feature visual='build' title='ビルド済みのファイルを、そのまま配信する'>
    Webサイトは SSG でビルドし、できあがったファイルをそのまま Cloudflare から配信します。表示のたびにサーバーで組み立てないので、素早く表示されます。

    <FeatureNote>
      ※ 配信には、Cloudflare Workers の Static Assets を使います。
    </FeatureNote>

  </Feature>
  <Feature visual='starter' wide title='一から作らずに始められる'>
    ページ、問い合わせフォーム、管理画面、データベースが最初からそろったスターターキットです。

    <DeployButton variant="secondary" />

  </Feature>
</FeatureGrid>

## すべて自分のCloudflareアカウントで動く

Webサイト、問い合わせフォーム、管理画面、データベースは、どれも自分のアカウントの中にあります。点線の枠は、必要なときに追加できる Cloudflare の機能です。

## 問い合わせは、ひとつの管理画面で確認できる

- 未読と既読を分けて管理します
- スパムの疑いがあるものも、消さずに別に表示します
- メールアドレスで検索し、CSV でエクスポートできます
