## Webサイト運営が、ご自身のCloudflareアカウントで完結

Webサイト、問い合わせフォーム、管理画面、データベースのすべてが、ご自身の Cloudflare アカウントの中で動きます。必要なサービスは、Cloudflare と GitHub だけです。

問い合わせフォームの投稿データは、Cloudflare の外に蓄積も送信もしません。Slack 通知用の Webhook を設定した場合も、Slack に送るのは新着の通知と管理画面へのリンクだけで、投稿データは含みません。管理画面のログインは Passkey だけで、パスワードは使いません。Cloudflare Access を組み合わせて、さらに安全にもできます。

## 管理画面でフォームの項目と投稿内容を管理

- 項目の追加・削除・並べ替えと、必須や選択肢の設定を、コードを変えずにできます
- 未読と既読を分けて管理します
- スパムの疑いがあるものも、消さずに別に表示します
- メールアドレスで検索し、CSV でエクスポートできます

</AdminShowcase>
