## 必要な機能だけを、自分のアカウントで

CMS（Webサイトの管理システム）や外部のフォームサービスを使わず、利用するサービスと保守の作業を明確にしています。

<FeatureGrid>
  <Feature visual='files' wide title='ページの更新は、ファイルを編集するだけ'>
    手作業でも、AI ツールに頼んでも更新できます。

    <FeatureNote>
      ※ Astro（ファイルからWebサイトを作るツール）を使用。AI ツール向けのガイド（`AGENTS.md`）付き。
    </FeatureNote>

  </Feature>
  <Feature visual='data' title='個人情報を、外部のフォームサービスに預けない'>
    問い合わせは自分のデータベースに保存し、パスキー（顔や指紋でログイン）で入る管理画面で確認します。

    <FeatureNote>※ 自分の Cloudflare アカウントの D1 データベースに保存します。</FeatureNote>

  </Feature>
  <Feature visual='pull-request' title='保守は、届いた更新の確認が中心'>
    更新は変更の提案（PR）として届きます。内容を確認して、反映（マージ）します。

    <FeatureNote>
      ※ 使うのは Cloudflare Workers・D1 と、GitHub のリポジトリ（コードの置き場所）です。[保守の作業一覧を見る →](/ja/docs/maintenance/)
    </FeatureNote>

  </Feature>
  <Feature visual='starter' wide title='一から作らずに始められる'>
    ページ、問い合わせフォーム、管理画面、データベース、更新の流れが最初からそろったスターターキットです。

    <FeatureNote>
      ※ Deploy to Cloudflare ボタンから、自分のアカウントに用意できます。
    </FeatureNote>

    <DeployButton />

  </Feature>
</FeatureGrid>

## すべて、自分の Cloudflare アカウントの中に

問い合わせが届いてから読むまでの流れです。コードは GitHub に置きます。

<LandingArchitecture />

<CloudflareNote>

### Cloudflare とは

Cloudflare は、Webサイトを世界中に速く届け、攻撃から守るサービスを提供している会社です。Webサイトの配信だけでなく、プログラムを動かす仕組みやデータベースも提供しています。

このスターターキットは、Webサイト・問い合わせの受付・データベース・管理画面のすべてを、自分の Cloudflare アカウントの中で動かします。関わるサービスが少ないので、何を自分で管理しているかがはっきりします。

</CloudflareNote>

</LandingSection>
