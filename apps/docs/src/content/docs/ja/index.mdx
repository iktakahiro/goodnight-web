## できること

goodnight-web を使うと、Webサイトによく必要な 3 つがそろいます。

- **ページとブログ。** Astro で作るWebサイトです。トップ、会社概要、サービス、お知らせ、ブログ、問い合わせ、プライバシーポリシーのページがあり、日本語と英語に対応します。ブログの記事は、リポジトリの中の Markdown ファイルです。
- **問い合わせフォーム。** 項目は管理画面で追加、削除、並べ替えでき、コードの編集もデプロイもいりません。送信は Turnstile（Cloudflare のボット対策）で確認し、回数を制限します。訪問者に応答する前に、D1（Cloudflare のデータベース）に保存します。
- **管理画面。** 管理者はパスキー（指紋や顔認証、PIN でログインするしくみ）でログインします。問い合わせを読み、未読/既読を切り替え、メールアドレスで検索できます。スパムの疑いは分けて表示します。問い合わせの削除、CSV の書き出し、フォームの項目の編集もできます。

## 使うサービス

すべて Cloudflare の上で動きます。ページを配信して API を動かす Worker（Static Assets 付き）1 つと、D1 データベース 1 つです。

ほかに使うのは GitHub だけで、あなたのWebサイトのリポジトリをそこに置きます。Slack 通知は任意です。

## 向いている人

- 顧客のWebサイトを作って引き渡す開発者や、小さな制作会社。
- 小さな会社やスタートアップで、Webサイトを担当している人。エンジニアでない人が、AI ツールでWebサイトを編集する使い方にも合います。

サーバーのコードを書く必要はありません。問い合わせ API と管理画面は npm パッケージで届き、その中身は編集しません。

## 残る保守

サーバーとランタイムの保守はなくなります。ただし、次の作業は残ります。あらかじめ予定に入れてください。

- **依存関係の更新 PR を確認してマージする。** goodnight-web の修正は、あなたのリポジトリに Dependabot（更新の PR を自動で作る GitHub の機能）の PR として届きます。自動ではマージされないので、確認してマージしてください。
- **Webサイト自体の依存関係を更新する。** Astro や Tailwind CSS などです。これも Dependabot の PR で届きます。
- **Cloudflare の変更に対応する。** 新しい `compatibility_date`（Workers の動作の基準日）や、無料プランの上限の変更などです。
- **リポジトリを private（非公開）に保つ。** Worker のシークレット（Worker に保存する秘密の値）も安全に管理してください。
- **プライバシーポリシーを専門家に確認してもらう。** 公開する前に済ませてください。
