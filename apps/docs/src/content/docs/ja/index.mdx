## Webサイト運営が、ご自身のCloudflareアカウントで完結

Webサイト、問い合わせフォーム、管理画面、データベースのすべてが、ご自身の Cloudflare アカウントの中で動きます。

<LandingArchitecture />

問い合わせの内容は Cloudflare の外に出ず、Slack 通知を使う場合も、送るのはサイト名、ページ、日時、管理画面へのリンクを載せた新着の通知だけです。管理画面のログインは Passkey のみに対応し、Cloudflare Access も追加できます。

<FeatureNote>
  ※ goodnight-web は Webサイト運営の SaaS
  ではありません。セルフホスティング用のスターターキットと、構築手順のドキュメントを公開しています。
</FeatureNote>

</LandingSection>

  <Feature visual='files' title='コンテンツは静的なファイルで管理'>
    ページ、お知らせ、ブログは、Markdown などの静的なファイルです。GitHub で管理し、Astro を使ってビルドします。

    <FeatureNote>
      ※ AI ツール向けのガイドとして、`AGENTS.md` も入っています。
    </FeatureNote>

  </Feature>
  <Feature visual='data' title='外部フォームサービスに依存しない個人情報管理'>
    問い合わせフォームは実装済みです。届いた内容は、ご自身の Cloudflare アカウント内の D1 データベースに保存され、管理画面で確認できます。

  </Feature>
  <Feature visual='starter' title='ゼロからつくらずにはじめられる'>

  </Feature>

## 管理画面で、問い合わせとフォームを管理

- 既読・未読、スパム疑いの別表示、メールアドレス検索、CSV 書き出しといった、問い合わせ対応の基本機能を備えています
- フォームの項目は、コードを変えずに編集できます
