## goodnight-web とは

goodnight-web は、多くの会社サイトに必要な 3 つのものをそろえます。

- **ページとブログ。** トップ、会社概要、サービス、お知らせ、ブログ、問い合わせ、プライバシーポリシーをそろえた Astro のサイトです。日本語と英語に対応します。ブログの記事はリポジトリの中の Markdown ファイルです。
- **問い合わせフォーム。** 送信内容は Turnstile で確認し、送信回数を制限し、訪問者に応答する前に D1 に保存します。
- **問い合わせを読む管理画面。** 管理者はパスキーでログインし、問い合わせを読み、未読と既読を切り替え、メールアドレスで検索し、スパムの疑いがあるものを分けて確認し、削除し、CSV で書き出せます。

すべて Cloudflare の上で動きます。Static Assets 付きの Worker が 1 つと、D1 データベースが 1 つです。ほかに使うサービスは、サイトのコピーを置く GitHub だけです。Slack 通知は任意です。

## 想定している利用者

- 顧客のサイトを作って引き渡す開発者や小さな制作会社。
- 小さな会社やスタートアップで会社サイトを担当している人。エンジニアでないことも多く、AI ツールでサイトを編集する想定です。

サーバーのコードを書く必要はありません。問い合わせ API と管理画面は npm パッケージから入り、中身は編集しません。

## 残る保守

goodnight-web を使うと、サーバーとランタイムの保守はなくなります。ただし、次の保守は残ります。あらかじめ予定に入れてください。

- **依存関係の更新 PR を確認してマージすること。** goodnight-web の修正は、あなたのリポジトリに Dependabot の PR として届きます。マージは誰も代わりにしてくれません。
- **サイト自体の依存関係の更新。** Astro や Tailwind CSS などです。これも Dependabot の PR で届きます。
- **Cloudflare の変更への対応。** 新しい `compatibility_date` や、無料プランの上限の変更などです。
- **リポジトリを private に保ち、** Worker のシークレットを安全に管理すること。
- **プライバシーポリシーを公開前に専門家に確認してもらうこと。**
