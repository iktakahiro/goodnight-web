## はじめに

- [はじめかた](/ja/docs/getting-started/): Deploy to Cloudflare ボタンでコピーを作り、シークレットを入力し、最初の管理者を作ります。
- [Turnstile を設定する](/ja/docs/setup/turnstile/): Turnstile のウィジェットを作ります。設定するまで、問い合わせフォームは送信を受け付けません。
- [お問い合わせフォームの項目を変える](/ja/docs/contact-form/): 管理画面で項目を編集します。バージョンと履歴、問い合わせ一覧、CSV の書き出しも説明します。

## 考え方

- [構成](/ja/docs/architecture/): 1 つのサイトを構成する部品と、問い合わせが送信されたときの流れ。
- [データベース](/ja/docs/database/): D1 のテーブル、クエリの書き方、マイグレーションがサイトに届いて適用される流れ。
- [配布と更新のしくみ](/ja/docs/distribution/): npm パッケージ、自分で持つ starter、Dependabot での更新、リポジトリを private にする理由。
- [しくみの詳細](/ja/docs/how-it-works/): パスキーや、Cron を使わない古いデータの削除など、設計の判断ごとのページ。

## リファレンス

- [セキュリティモデル](/ja/docs/security/): 管理画面と問い合わせフォームを守るものと、goodnight-web では守れないもの。
- [プライバシーについて](/ja/docs/privacy/): データの保存場所、削除したデータを復元できる期間、プライバシーポリシーの雛形の内容。
