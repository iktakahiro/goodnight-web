---
title: 生の IP アドレスを保存しない
description: goodnight-web は、訪問者の IP アドレスを保存もログ出力もしません。保存するのは HMAC-SHA256(ip, IP_HASH_SECRET) で、回数制限や同じ送信者の確認にはこれで足ります。
---

<Callout type='info'>
  コードの抜粋は、サーバーのパッケージができたら追加します。
</Callout>

## 何をするか

- 問い合わせが送信されるたびに、Worker は `ip_hash = HMAC-SHA256(ip, IP_HASH_SECRET)` を計算します。
- D1 に保存するのは `ip_hash` だけです。生の IP アドレスは D1 に書かず、ログにも出しません。
- Rate Limiting binding のキーにも `ip_hash` を使います。

## なぜこう作るか

- IP アドレスは個人を特定する手がかりになります。保存すれば、持っていて守らなければならない個人情報が増えます。
- 同じ IP アドレスからは必ず同じ `ip_hash` ができるので、回数制限も、複数の問い合わせが同じ送信者から来たことの確認もできます。
- IP アドレスをそのまま SHA-256 にしただけでは、簡単に元に戻せます。IPv4 アドレスは約 43 億通りしかなく、すべて試せるからです。秘密の鍵を使う HMAC なら、鍵がなければ元に戻せません。鍵は Worker の中にとどまります。
- `IP_HASH_SECRET` は変えないでください。変えると、新しいハッシュが古いハッシュと一致しなくなります。
