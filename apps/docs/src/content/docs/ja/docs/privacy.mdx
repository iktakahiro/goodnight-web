## 保存するもの

問い合わせでは、訪問者が入力したもの、プライバシーポリシーに同意した時刻、送信したページ、ユーザーエージェント（ブラウザや OS の情報）、Cloudflare が判定した国、IP アドレスのハッシュ（`ip_hash`）を保存します。生の IP アドレスは保存しません。[生の IP アドレスを保存しない](/ja/docs/how-it-works/ip-hashing/)を参照してください。

訪問者が入力する内容は、フォームによって変わります。メールアドレスはいつも集めます。ほかの項目は、管理者が管理画面で決めます（最初のバージョンでは、お名前、会社名、電話番号、お問い合わせの種類、お問い合わせ内容）。[お問い合わせフォームの項目を変える](/ja/docs/contact-form/)を参照してください。別の種類の個人情報を集める項目を足したときは、プライバシーポリシーの取得する情報の一覧も直してください。

問い合わせは保持期間（既定は 180 日）を過ぎると削除します。[Cron を使わない古いデータの削除](/ja/docs/how-it-works/data-pruning/)を参照してください。

## データは日本の外に保存されます

D1 で保存場所を指定できるのは、EU、FedRAMP、US だけです。日本国内に固定することはできません（[Cloudflare: D1 data location](https://developers.cloudflare.com/d1/configuration/data-location/)）。そのため、プライバシーポリシーの雛形には、データが外国（米国など）のサーバーに保存されることがあること、保存先の事業者、その国の個人情報の制度を確認したことを書いています。個人情報保護法は、外国で個人データを取り扱う事業者に、その国の個人情報の保護に関する制度などを把握することを求めています。制度を具体的に書く場合に備えて、雛形のコメントで個人情報保護委員会が公開している各国の制度の調査結果を案内しています。

## 削除したデータも、しばらくは復元できます

D1 の Time Travel を使うと、データベースを過去の時点に戻せます。Workers の無料プランでは 7 日前まで、有料プランでは 30 日前までです（[Cloudflare: Time Travel](https://developers.cloudflare.com/d1/reference/time-travel/)）。そのため、削除した問い合わせが完全に消えるのはその期間の後です。雛形には、無料プランで削除が完全に反映されるまで最大 7 日かかると書いています。有料プランを使うなら 30 日に直してください。

## 第三者のサービス

- **Turnstile。** 問い合わせフォームは Cloudflare Turnstile を使います。雛形にもそのことを書いています。
- **フォント。** サイトも管理画面も Web フォントを読み込まないので、フォントの配信サービスに訪問者のリクエストが届くことはありません。[スタイルとフォント](/ja/docs/architecture/#styles-and-fonts)を参照してください。
- **Slack。** Slack 通知を有効にしても、通知に含めるのは件数、受信日時、リンクだけです。フォームにどんな項目があっても、個人情報もフォームの項目の値も Slack に送りません。

## 雛形について

starter には日本語と英語の雛形があります（`src/content/pages/ja/privacy.md` と `src/content/pages/en/privacy.md`）。雛形には、代表者の氏名や、開示・訂正・削除などの請求の窓口を含め、サンプルの会社の情報が入っています。自社の情報に書き換え、専門家に確認してもらったあとで、ページ冒頭の注意書きを削除してください。
