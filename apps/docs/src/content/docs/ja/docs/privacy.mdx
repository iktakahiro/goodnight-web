## 保存するもの

問い合わせでは、訪問者が入力したもの（名前、メールアドレス、会社名、電話番号、種別、本文）、プライバシーポリシーに同意した時刻、送信したページ、ユーザーエージェント、Cloudflare が判定した国、`ip_hash` を保存します。生の IP アドレスは保存しません。[生の IP アドレスを保存しない](/ja/docs/how-it-works/ip-hashing/)を参照してください。

問い合わせは保持期間（既定は 180 日）を過ぎると削除します。[Cron を使わない古いデータの削除](/ja/docs/how-it-works/data-pruning/)を参照してください。

## データは日本の外に保存されます

D1 で保存場所を指定できるのは、EU、FedRAMP、US だけです。日本国内に固定することはできません（[Cloudflare: D1 data location](https://developers.cloudflare.com/d1/configuration/data-location/)）。そのため、プライバシーポリシーの雛形には、データが外国（米国など）のサーバーに保存されることを書き、保存する国とその国の個人情報の制度を説明しています。個人情報保護法は、外国で個人データを取り扱う事業者に、その国の環境を把握することを求めています。

## 削除したデータも、しばらくは復元できます

D1 の Time Travel を使うと、データベースを過去の時点に戻せます。Workers の無料プランでは 7 日前まで、有料プランでは 30 日前までです（[Cloudflare: Time Travel](https://developers.cloudflare.com/d1/reference/time-travel/)）。そのため、削除した問い合わせが完全に消えるのはその期間の後です。雛形には、無料プランで削除が完全に反映されるまで最大 7 日かかると書いています。有料プランを使うなら 30 日に直してください。

## 第三者のサービス

- **Turnstile。** 問い合わせフォームは Cloudflare Turnstile を使います。雛形にもそのことを書いています。
- **Slack。** Slack 通知を有効にしても、通知に含めるのは件数、種別、リンクだけです。個人情報は Slack に送りません。
