---
title: 保守の作業
icon: ClipboardCheck
description: Webサイトが動き始めたあとに残る作業の一覧です。
---

サーバーとランタイムの保守はなくなります。ただし、次の作業は残ります。あらかじめ予定に入れてください。

- **依存関係の更新 PR を確認してマージする。** goodnight-web の修正は、あなたのリポジトリに Dependabot（更新の PR を自動で作る GitHub の機能）の PR として届きます。自動ではマージされないので、確認してマージしてください。
- **Webサイト自体の依存関係を更新する。** Astro や Tailwind CSS などです。これも Dependabot の PR で届きます。
- **Cloudflare の変更に対応する。** 新しい `compatibility_date`（Workers の動作の基準日）や、無料プランの上限の変更などです。
- **リポジトリを private（非公開）に保つ。** Worker のシークレット（Worker に保存する秘密の値）も安全に管理してください。
- **プライバシーポリシーを専門家に確認してもらう。** 公開する前に済ませてください。

サーバーのコードを書く必要はありません。問い合わせ API と管理画面は npm パッケージで届き、その中身は編集しません。パッケージの修正は、上の更新 PR として届きます。
